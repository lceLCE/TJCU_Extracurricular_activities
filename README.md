# 天津商业大学体育打卡定位插件

使用codex构建，用于在Chrome中访问天津商业大学课外活动打卡平台时能够正常获取位置

目前已将经纬度固定在天津商业大学体育馆，直接安装即可无痛体育打卡（笑）

本插件仅在电脑版 Chrome 访问 `peawx.sec.tjcu.edu.cn` 时生效，把网页的 `wx.getLocation` 调用连接到 Chrome的真实定位服务。

若需使用真实定位服务，请把 `offscreen.js` 中的 `sendResponse(FakeResponse);` 注释掉，把其余注释掉的部分取消注释即可

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `Chrome位置兼容插件`。
5. 接受“检测您的实际位置”权限，然后重新加载目标网站。

## 使用

正常登录真实网站后点击“获取位置”。

插件不提供坐标输入，不读取登录 cookie，不修改接口，也不会自动提交表单。定位成功后，坐标会按网页原有 `wx.getLocation` 回调交给目标页面。
