# 天津商业大学课外活动定位兼容插件

使用codex构建

本插件仅在电脑版 Chrome 访问 `peawx.sec.tjcu.edu.cn` 时生效，把网页的 `wx.getLocation` 调用连接到 Mac 的真实定位服务。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `Chrome位置兼容插件`。
5. 接受“检测您的实际位置”权限，然后重新加载目标网站。

## 使用

正常登录真实网站后点击“获取位置”。首次定位时，请确保 macOS 的“系统设置 → 隐私与安全性 → 定位服务”已允许 Chrome 使用位置。

插件不提供坐标输入，不读取登录 cookie，不修改接口，也不会自动提交表单。定位成功后，坐标会按网页原有 `wx.getLocation` 回调交给目标页面。

## 自检

```sh
node test.js
```
